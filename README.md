En commit är en sparad ögonblicksbild av ändringarna i Git-historiken.

Git är verktyget som hanterar versionshistoriken, 
GitHub är en onlinetjänst där Git-repositoryn 
kan lagras och delas.

Examinationen kräver ett publikt repo och synlig historik så 
att läraren kan se koden och kontrollera commits och 
utvecklingen över tid.
